# Musical Vibes — музыкальный плеер звуков по категориям

Pet-проект для портфолио (2026). Плеер с пятью тематическими категориями - у каждой свой акцентный цвет, иконка и подборка звуков.

## Моя роль

- Продумал структуру продукта: категории, логику переключения, поведение shuffle/repeat, UX-детали (что должно быть заметно пользователю, а что нет).
- Спроектировал архитектуру данных: звуки вынесены из кода в отдельный `data.json`, а не хардкожены в разметке.
- Принимал все продуктовые решения по ходу разработки: сознательно не стал добавлять поиск и избранное - для 15 "треков" это избыточно и не решает реальную проблему пользователя.

## Что сделано

- 5 категорий (Философия, Романтика, Веселые, Грустные, Ностальгия), каждая с собственным цветом и эмодзи-иконкой.
- Play/Pause, Next/Prev, Shuffle (без повтора подряд одного и того же трека), Repeat (зацикливание конкретного трека).
- Прогресс-бар с перемоткой, таймер, регулировка громкости.
- Данные (звуки, цвета, пути к аудио) загружаются асинхронно из `data.json` через `fetch` - интерфейс строится динамически.
- Интерфейс подсвечивается акцентным цветом текущей категории (сайдбар и панели плеера).
- Адаптивная верстка под мобильные экраны.

## Технологии

HTML, CSS, JavaScript - без фреймворков и сборщиков, чтобы весь код оставался прозрачным и легко читаемым.

## Звук

Аудио - бесплатные lo-fi/эмбиент-треки с [Pixabay](https://pixabay.com/music/) (лицензия Free for commercial use), подобранные под настроение каждой категории.

## Статус
